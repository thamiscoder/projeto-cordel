# Projeto Cordel

Página web estática desenvolvida como estudo do curso de **HTML5 e CSS3** do **Curso em Vídeo**, no **Capítulo 20 - Mini-projeto Cordel**.

O projeto apresenta o cordel **Cordel Moderno**, de **Milton Duarte**, em uma página simples, responsiva e com efeito visual de imagens de fundo no estilo parallax.

## Sobre o projeto

Este repositório foi criado com fins de estudo e prática de desenvolvimento web front-end. A proposta é transformar um texto literário em uma página visualmente agradável, aplicando conceitos fundamentais de HTML e CSS aprendidos durante o curso.

O foco do projeto está em:

- estruturar uma página com HTML semântico;
- aplicar estilos externos com CSS;
- trabalhar com fontes importadas;
- utilizar imagens de fundo;
- criar seções alternadas entre fundo claro e fundo com imagem;
- aplicar efeito parallax com `background-attachment: fixed`;
- organizar um layout de leitura para o cordel;
- praticar links externos, cabeçalho e rodapé.

## Como visualizar o projeto

Você pode abrir o projeto diretamente pelo navegador.

### Opção 1: clonar o repositório

```bash
git clone https://github.com/thamiscoder/projeto-cordel.git
```

Depois, entre na pasta:

```bash
cd projeto-cordel
```

E abra o arquivo `index.html` no navegador.

### Opção 2: baixar o ZIP

1. Acesse o repositório no GitHub;
2. clique em **Code**;
3. escolha **Download ZIP**;
4. extraia os arquivos;
5. abra o `index.html` no navegador.
